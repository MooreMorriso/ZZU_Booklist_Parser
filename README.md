# 郑大教材书单解析器

一个用于 **郑州大学教材系统** 的油猴脚本。

它可以在你登录郑大教材系统后，自动读取当前教材订购信息，并整理出：

* 课程名称
* 教材名称
* 作者
* 出版社
* ISBN
* 教材原价
* 郑大教材价格
* 是否已在郑大教材系统选购

同时，每本书旁边都提供 **“复制 ISBN”** 按钮。你可以把 ISBN 直接粘贴到某东、某宝、某多多、孔夫子网等平台搜索，对比价格后自行选择购买渠道。

---

## 一、这个脚本是干什么的？

郑大的教材系统里会显示本学期课程对应的教材。

这个脚本做的事情很简单：

1. 你正常登录郑大教材系统。
2. 脚本自动读取教材信息。
3. 点击页面右下角的 **“📚 查看教材书单”**。
4. 就能看到整理好的教材列表。
5. 点击某本书旁边的 **“复制 ISBN”**，然后去购物平台搜索即可。

例如：

```text
课程：数字图像处理
教材：数字图像处理（第四版）
作者：冈萨雷斯（著）阮秋琦（译）
出版社：电子工业出版社
ISBN：9787121377471
原价：¥159.00
郑大教材价：¥127.20
状态：未选购
```

ISBN 基本可以理解为一本书的“身份证号”。

相比只搜索书名，用 ISBN 搜索通常更容易找到 **完全相同版本的教材**。

# 三、安装油猴

“油猴”是一个浏览器扩展，可以让浏览器运行一些用户脚本。

常见的油猴扩展叫：

**Tampermonkey**

图标通常是一个黑色方块，中间有两个白色圆点。

---

## 方法一：Microsoft Edge 浏览器

如果你用的是 Windows，比较推荐使用 Edge。

### 第 1 步：打开 Edge 扩展商店

打开 Edge，在地址栏搜索：

```text
Tampermonkey
```

也可以进入 Edge 的扩展商店，再搜索：

```text
Tampermonkey
```

### 第 2 步：安装

找到 **Tampermonkey** 后：

点击：

**获取**

然后浏览器可能会弹出提示，再点击：

**添加扩展**

安装完成以后，浏览器右上角一般会出现 Tampermonkey 图标。

如果没有看到，可以点击浏览器右上角的：

**扩展 / 拼图图标**

然后把 Tampermonkey 固定到工具栏。

## 方法二：Google Chrome 浏览器

然后确认：

即可。

## 方法三：Firefox 浏览器

## 第 4 步：点击右下角按钮

## 第 5 步：查看教材

# 六、怎么买书？

脚本顶部会看到类似下面的提示：

> 下边这些是从“郑大教材”系统中提取到的教材订购信息，你当然可以选择某东、某宝、某多多、孔夫子网等地方购买你的教材。书号已经给你了，把 ISBN 书号复制到那些平台的搜索框里查找即可。

例如系统显示：

```text
数字图像处理（第四版）

ISBN：
9787121377471
```

点击旁边：

**📋 复制 ISBN**

然后打开你常用的购物平台。

在搜索框里直接粘贴：

```text
9787121377471
```

搜索即可。

这样比只搜索：

```text
数字图像处理
```

更准确，因为同一本教材可能存在：

* 不同出版社
* 不同版本
* 不同年份
* 中文版 / 英文版
* 第三版 / 第四版
* 不同作者或译者

所以建议优先按照 **ISBN** 搜索和核对。

# 七、几个按钮分别是干什么的？

## 📋 复制 ISBN

每本书都有一个独立按钮。

例如：


一次复制当前书单中所有教材的 ISBN。

效果类似：

```text

9787121377471
978730xxxxxxxx
```

---

会复制比较完整的教材信息，例如：

```text
Ctrl + R
```

对于普通用户，**不建议自己打开开发者工具寻找 Token**。

# 十、为什么郑大教材价格和原价不一样？

教材系统返回的数据中通常会包含：

```text
教材原价
教材折扣
```

例如：

```text
原价：¥159.00
折扣：8 折
```

那么脚本会显示：

```text
郑大教材价：¥127.20
```

也就是：

```text
159 × 0.8 = 127.2
```

如果系统已经返回了实际支付价格，则会优先显示系统中的实际价格。

---

# 十一、“未选购”是什么意思？

如果显示：

```text
未选购
```

表示郑大教材系统当前返回的状态是没有在系统中选购这本书。

如果显示：

```text
已选购
```

则表示系统返回的状态为已经选购。

这里显示的是 **郑大教材系统中的记录**。

如果你已经在其他购物平台买了这本书，脚本当然无法知道，因此仍可能显示“未选购”。

---

# 十二、脚本安全吗？

脚本的设计用途只是：

1. 在郑大教材网页中读取当前登录状态下的接口信息。
2. 从郑大教材后台接口获取你的教材书单。
3. 在本地浏览器中整理和展示。
4. 提供复制 ISBN 等功能。

正常使用过程中：

**不需要把学校密码输入脚本。**

登录仍然是在学校自己的统一身份认证页面完成。

同时需要注意：

**登录 Token 属于登录凭证，不要截图、复制或发给别人。**

README、Issues、群聊等公开场合，也不要粘贴自己真实的 Token。

例如看到这种内容：

```text
token=eyJ...
```

不要公开发送。

# 十四、免责声明

本脚本为方便查看教材信息而制作，与郑州大学及教材系统官方无关。

脚本展示的数据来自当前账号能够正常访问的郑大教材系统接口，实际教材信息、课程要求、购买状态、价格和订购安排请以学校及任课教师通知为准。

使用第三方购物平台购买教材时，请自行核对：

* ISBN
* 教材名称
* 作者
* 出版社
* 版次
* 新旧程度

尤其不要只看封面相似就直接购买。

**ISBN 相同通常是判断是否为同一版本教材的重要依据。**
